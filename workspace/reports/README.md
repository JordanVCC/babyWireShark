# Analysis Reports

This folder contains all diagnostic analysis reports generated by the BabyWireShark agent.

## Naming Convention

Reports follow the format: `YYYY-MM-DD_<analysis-type>_<identifier>.md`

Examples:
- `2026-10-15_FAS_5607272_VCTS271.md`
- `2026-10-15_UDS_decode_capture1.md`
- `2026-10-15_DTC_analysis_vehicle2.md`

## Report Structure

Each report begins with the date and includes:

1. **Header** - Date, test ID, vehicle/capture identifier
2. **Test Metadata** - Duration, transport, ECU targets, capture info
3. **Service Distribution** - UDS service counts and status
4. **Procedure Stages** - Step-by-step analysis with findings
5. **Error Analysis** - Negative responses, NRCs, blocked errors
6. **Conclusions** - Root cause, evidence, recommendations
7. **Raw Data** - Complete request/response bytes when needed

## Guidelines

- Always start with `# Report: YYYY-MM-DD`
- Use tables for structured data
- Include exact hex values and timestamps
- Separate observed facts from interpretations
- State confidence levels for uncertain findings
- Preserve complete command/response sequences for FAS debugging

## Accessing Reports

Reports are indexed by date. To find recent analyses:
```bash
ls -lt workspace/reports/ | head -10
```

To search for a specific test or vehicle:
```bash
grep -l "5607272\|VCTS271" workspace/reports/*.md
```
